# NBA game model: the Kalman state, walk-forward

Each season is forecast by a filter tuned only on the seasons before it and scored beside the references on every game the odds archive prices. Scores: CRPS and MAE on the margin, Brier on the home win, the expected calibration error of the home win probability.
